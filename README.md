# Symbios

Одностраничный сайт компании Symbios (анализ и визуализация больших массивов данных):
<https://spectr747.github.io/>.

Сайт статический: HTML, CSS и немного JavaScript без сборки. Всё, что лежит в ветке `main`,
сразу публикуется GitHub Pages.

## Запуск локально

Нужен любой статический сервер (открывать `index.html` двойным кликом не стоит: модульный
JavaScript по `file://` не работает).

```sh
python3 -m http.server 8000
# или
npm start
```

Затем откройте <http://localhost:8000/>.

## Структура

```
index.html              вся разметка: шапка, разделы, подвал, лайтбокс
css/style.css           все стили, обе темы (mobile-first, оглавление в начале файла)
js/main.js              поведение: тема, меню, слайдер «до/после», лайтбокс, форма
fonts/                  шрифт Nunito 400 (кириллица и латиница), лицензия OFL
img/elements/           фон, картинки слайдера «до/после», иконки услуг и тарифов
img/portfolio/          полноразмерные работы (JPEG + WebP) и thumbs/ — миниатюры для сетки
img/logo/               логотип; symbios.png — исходник 300×300, из него сделаны остальные
docs/refactor-baseline/ скриншоты и метрики до рефакторинга (на сайте не используются)
docs/redesign/          скриншоты нового дизайна в обеих темах
```

## Как устроена страница

Одна страница, разделы идут друг за другом и прокручиваются: Главная (`#home`), Услуги
(`#services`), Портфолио (`#portfolio`), Стоимость (`#prices`), Контакты (`#contacts`).
Шапка прилипает к верху; пункт меню раздела, который сейчас на экране, подсвечивается.
На узких экранах меню прячется под кнопку-бургер.

Чтобы добавить раздел: новый `<section class="section" id="имя">` внутри `<main>` и пункт меню
`<a class="nav-link" href="#имя">`. Блоки с атрибутом `data-reveal` плавно появляются при прокрутке.

## Тёмная и светлая тема

Кнопка с солнцем/луной в шапке переключает тему. Выбор запоминается в браузере посетителя
(`localStorage`); пока посетитель ничего не выбирал, тема следует настройке системы.
Тему ставит маленький скрипт в `<head>` `index.html` ещё до отрисовки, поэтому страница не мигает.

Все цвета — переменные в начале `css/style.css`: блок `:root, [data-theme='dark']` для тёмной темы
и `[data-theme='light']` для светлой. Отличия тем, которые переменными не выразить (фон первого экрана,
цветная полоса у карточек услуг, тёмный «популярный» тариф), собраны в разделе «6. Отличия тем».

## Где менять контент

- **Тексты услуг** — раздел `id="services"` в `index.html`, по одной карточке `<article class="card service">` на услугу.
- **Тарифы** — раздел `id="prices"`. Один пункт тарифа — одна строка:
  `<li class="plan-item">` с иконкой `#icon-check` («входит») или
  `<li class="plan-item is-excluded">` с иконкой `#icon-times` («не входит», серый текст).
  Выделенный тариф — класс `plan--featured` и бейдж `<span class="badge">`.
- **Портфолио** — раздел `id="portfolio"`, список `#portfolio-gallery`. На одну работу нужны:
  `img/portfolio/N.jpg` и `N.webp` (полный размер для лайтбокса, 1280×800),
  `img/portfolio/thumbs/N.jpg` и `N.webp` (миниатюра 700×438). Подпись в лайтбоксе — атрибуты
  `data-title` и `data-caption` у ссылки, они же видны под миниатюрой.
- **Прелоадер** — блок `.preloader` в начале `<body>`: логотип встроен прямо в HTML (data URI), чтобы появиться сразу. Скрипт убирает его после загрузки страницы, но не позже чем через 1 с; без JavaScript CSS прячет его через 3 с.
- **Год в подвале** — проставляется скриптом автоматически, в HTML лежит запасное значение.

Картинки перед добавлением стоит сжать (например, [Squoosh](https://squoosh.app/)): JPEG
качество ~78, WebP ~75.

## Форма обратной связи

Форма отправляется через [Formspree](https://formspree.io/) (бесплатный тариф, бэкенд не нужен).
Адрес формы — атрибут `action` формы в `index.html`: `https://formspree.io/f/xpppneyq`.
Почта, на которую приходят заявки, настраивается в кабинете formspree.io, а не в коде.

Чтобы подключить другую форму, создайте её на formspree.io и замените ID в `action`.
Если вместо ID оставить заглушку `YOUR_FORM_ID`, форма покажет «форма ещё не подключена» и ничего не отправит.
Поле `_gotcha` — скрытая ловушка для спам-ботов, его не трогайте.

## Вход и регистрация

На статическом сайте нет сервера авторизации, поэтому раздел «Вход» и пункт «Вход» в меню
**скрыты флагом**. Разметка осталась в `index.html` (элементы с `data-feature="login"`).
Чтобы вернуть их, в начале `js/main.js` поменяйте `login: false` на `login: true`.
Отправка формы входа сейчас ничего не делает (`TODO` в `js/main.js`), её нужно подключить к бэкенду.

## Зависимости

Внешних CDN нет: всё нужное лежит в репозитории, поэтому сайт не зависит от чужих серверов.

| Что        | Версия                          | Где      | Лицензия    |
| ---------- | ------------------------------- | -------- | ----------- |
| Nunito 400 | Google Fonts / Fontsource 5.3.0 | `fonts/` | SIL OFL 1.1 |

Слайдер «до/после», лайтбокс портфолио, меню и переключатель темы написаны в `js/main.js` и
`css/style.css` (слайдер по мотивам BeerSlider, MIT).

CSS-фреймворков и библиотек нет: сетка, меню и кнопки написаны в `css/style.css`.

## Проверки

Инструменты нужны только разработчику, сайт работает и без них. Нужен Node.js 20+.

```sh
npm install
npm run lint      # html-validate, stylelint, prettier --check
npm run format    # автоформатирование
```

Те же проверки запускает GitHub Actions на каждый pull request (`.github/workflows/lint.yml`).
HTML дополнительно стоит проверить в [W3C Nu HTML Checker](https://validator.w3.org/nu/).

## Деплой

GitHub Pages публикует сайт из корня ветки `main` (Settings → Pages → Deploy from a branch).
Сборки нет: смерджили изменения в `main` — через минуту-две они на сайте.
Файл `.nojekyll` отключает обработку Jekyll: файлы отдаются как есть.
