# Symbios

Одностраничный сайт компании Symbios (анализ и визуализация больших массивов данных):
<https://spectr747.github.io/>.

Сайт статический: HTML, CSS и немного JavaScript без сборки. Всё, что лежит в ветке `main`,
сразу публикуется GitHub Pages.

## Запуск локально

Нужен любой статический сервер (открывать `index.html` двойным кликом не стоит: модульный
JavaScript по `file://` не работает).

```sh
python3 -m http.server 8000
# или
npm start
```

Затем откройте <http://localhost:8000/>.

## Структура

```
index.html              вся разметка: шапка, 6 разделов, подвал, лайтбокс
css/style.css           свои стили (mobile-first, оглавление в начале файла)
js/main.js              поведение: разделы и адреса, слайдер «до/после», лайтбокс, форма
vendor/bootstrap-5.3.8/ Bootstrap 5.3.8 (CSS + bundle с Popper), лицензия MIT
fonts/                  шрифт Nunito 400 (кириллица и латиница), лицензия OFL
img/elements/           фон, картинки слайдера «до/после», иконки услуг и тарифов
img/portfolio/          полноразмерные работы (JPEG + WebP) и thumbs/ — миниатюры для сетки
img/logo/               логотип; symbios.png — исходник 300×300, из него сделаны остальные
docs/refactor-baseline/ скриншоты и метрики до рефакторинга (на сайте не используются)
```

## Как устроены разделы

Разделы (Главная, Услуги, Портфолио, Стоимость, Контакты, Вход) — это слайды карусели
Bootstrap внутри `<main>`. У каждого слайда есть атрибут `data-section`, он же адрес раздела:
`https://spectr747.github.io/#services` открывает «Услуги». Ссылки меню — обычные ссылки
`href="#services"`, `js/main.js` переключает слайд при смене адреса, поэтому работают
клавиатура, кнопки «Назад/Вперёд» и прямые ссылки на раздел.

Чтобы добавить раздел: новый `<section class="carousel-item" data-section="имя" …>` внутри
`.carousel-inner` и пункт меню `<a class="nav-link" href="#имя">`.

## Где менять контент

- **Тексты услуг** — раздел `data-section="services"` в `index.html`, по одной карточке `<article class="card">` на услугу.
- **Тарифы** — раздел `data-section="prices"`. Один пункт тарифа — одна строка:
  `<li class="list-group-item">` с иконкой `#icon-check` («входит») или
  `<li class="list-group-item is-excluded">` с иконкой `#icon-times` («не входит», серый текст).
- **Портфолио** — раздел `data-section="portfolio"`, список `#portfolio-gallery`. На одну работу нужны:
  `img/portfolio/N.jpg` и `N.webp` (полный размер для лайтбокса, 1280×800),
  `img/portfolio/thumbs/N.jpg` и `N.webp` (миниатюра 700×438). Подпись в лайтбоксе — атрибуты
  `data-title` и `data-caption` у ссылки, текстовая альтернатива — `alt` у миниатюры.
- **Год в подвале** — проставляется скриптом автоматически, в HTML лежит запасное значение.

Картинки перед добавлением стоит сжать (например, [Squoosh](https://squoosh.app/)): JPEG
качество ~78, WebP ~75.

## Форма обратной связи

Форма отправляется через [Formspree](https://formspree.io/) (бесплатный тариф, бэкенд не нужен).

1. Зарегистрируйтесь на formspree.io, создайте форму и подтвердите почту, на которую должны приходить заявки.
2. Скопируйте ID формы (вида `xyzabcde`) и замените `YOUR_FORM_ID` в атрибуте `action` формы в `index.html`:
   `action="https://formspree.io/f/xyzabcde"`.

Пока ID не указан, форма показывает сообщение «форма ещё не подключена», письма не уходят.
Поле `_gotcha` — скрытая ловушка для спам-ботов, его не трогайте.

## Вход и регистрация

На статическом сайте нет сервера авторизации, поэтому раздел «Вход» и иконка входа в меню
**скрыты флагом**. Разметка осталась в `index.html` (элементы с `data-feature="login"`).
Чтобы вернуть их, в начале `js/main.js` поменяйте `login: false` на `login: true`.
Отправка формы входа сейчас ничего не делает (`TODO` в `js/main.js`), её нужно подключить к бэкенду.

## Зависимости

Внешних CDN нет: всё нужное лежит в репозитории, поэтому сайт не зависит от чужих серверов.

| Что                                  | Версия                          | Где                       | Лицензия    |
| ------------------------------------ | ------------------------------- | ------------------------- | ----------- |
| Bootstrap (CSS + JS bundle с Popper) | 5.3.8                           | `vendor/bootstrap-5.3.8/` | MIT         |
| Nunito 400                           | Google Fonts / Fontsource 5.3.0 | `fonts/`                  | SIL OFL 1.1 |

Слайдер «до/после», лайтбокс портфолио и анимации появления написаны в `js/main.js` и
`css/style.css` (слайдер по мотивам BeerSlider, анимации — по ключевым кадрам animate.css, обе MIT).

Обновление Bootstrap: скачайте `bootstrap.min.css` и `bootstrap.bundle.min.js` нужной версии,
положите в `vendor/bootstrap-<версия>/` и поправьте два пути в `<head>` `index.html`.

## Проверки

Инструменты нужны только разработчику, сайт работает и без них. Нужен Node.js 20+.

```sh
npm install
npm run lint      # html-validate, stylelint, prettier --check
npm run format    # автоформатирование
```

Те же проверки запускает GitHub Actions на каждый pull request (`.github/workflows/lint.yml`).
HTML дополнительно стоит проверить в [W3C Nu HTML Checker](https://validator.w3.org/nu/).

## Деплой

GitHub Pages публикует сайт из корня ветки `main` (Settings → Pages → Deploy from a branch).
Сборки нет: смерджили изменения в `main` — через минуту-две они на сайте.
Файл `.nojekyll` отключает обработку Jekyll: файлы отдаются как есть.
