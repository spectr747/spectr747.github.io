# Эталон «до» рефакторинга

Снято 2026-11-06 с коммита `92b3e47` (ветка `main`). Эти файлы не участвуют в работе сайта,
на них нет ссылок со страниц.

## Как снималось

- Локальный статический сервер с gzip и `Cache-Control: max-age=600` (как у GitHub Pages).
- CDN-ресурсы (Bootstrap 4.0.0, jQuery 3.2.1 slim, Popper 1.12.9, Font Awesome 5.12.0,
  animate.css 3.5.2, CSS lightgallery 1.3.2, lightgallery.js 1.4.0 + lg-fullscreen.js)
  подставлены локально теми же версиями из npm: из среды, где выполнялся рефакторинг,
  внешние CDN недоступны. Поэтому цифры ниже — **лучший случай** для старой версии:
  в проде добавляются задержки соединений с пятью сторонними доменами, а `cdn.rawgit.com`
  (lightGallery) закрыт с 2019 года, и галерея там не работает.
- Скриншоты: Playwright/Chromium, полная высота страницы, ширины 375 / 768 / 1280 / 1920 / 3840 px,
  разделы 0–5 (Главная, Услуги, Портфолио, Стоимость, Контакты, Вход),
  плюс открытое мобильное меню и открытый лайтбокс. Файлы `screenshots/<ширина>-<раздел>.webp`.

## Консоль и сеть

С локальной подстановкой CDN ошибок в консоли нет. В проде ожидаемо падают два запроса к
`cdn.rawgit.com` (lightgallery.js, lg-fullscreen.js), из-за чего `lightGallery is not defined`
и клик по миниатюре портфолио открывает голый JPEG вместо лайтбокса.

Визуальные дефекты, видимые на эталоне: пустое место вместо иконки у пункта «Преобразование
форматов данных» в тарифе «Стандарт» (`fa-shield-check` есть только в Font Awesome Pro);
крестик открытого бургер-меню «уезжает» на логотип (`menu-375.webp`); иконки панели лайтбокса
отображаются неверными глифами (CSS от другой версии библиотеки, `lightbox-1280.webp`).
